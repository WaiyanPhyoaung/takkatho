## 1. Database Connection Pooling

HTTP Request ဝင်လာတိုင်း Database connection အသစ် ဖွင့်-ပိတ် လုပ်နေမယ်ဆိုရင် Server အရမ်းနှေးသွားပါမယ်။ ဒါကြောင့် Connection Pool (`pg.Pool`, Prisma, သို့မဟုတ် Mongoose connection pool) ကို App စတင်ချိန်မှာ တစ်ကြိမ်သာ တည်ဆောက်ထားပြီး ပြန်လည် မျှဝေသုံးစွဲရပါတယ်။

```javascript
// db/pool.js (PostgreSQL Example with pg)
import pg from "pg";

export const pool = new pg.Pool({
  connectionString: process.env.DATABASE_URL,
  max: 20,                 // တစ်ပြိုင်နက် အများဆုံး Connections 20
  idleTimeoutMillis: 30000,
});

// SQL Injection ကာကွယ်ရန် Parameterized Query ($1) ကို အမြဲသုံးပါ
export async function getUserByEmail(email) {
  const { rows } = await pool.query(
    "SELECT id, email, role FROM users WHERE email = $1",
    [email],
  );
  return rows[0] ?? null;
}
```

## 2. Node.js Built-in Test Runner (`node --test`)

Modern Node.js တွင် Jest သို့မဟုတ် Mocha ထပ် Install စရာမလိုဘဲ **`node:test`** နှင့် **`node:assert/strict`** တို့ တစ်ပါတည်း ပါဝင်လာပါတယ်။

```javascript
// tests/math.test.js
import test from "node:test";
import assert from "node:assert/strict";

function calculateDiscount(price, percent) {
  if (price < 0 || percent < 0 || percent > 100) {
    throw new Error("Invalid discount inputs");
  }
  return price * (1 - percent / 100);
}

test("applies 20% discount correctly", () => {
  assert.equal(calculateDiscount(10000, 20), 8000);
});

test("throws on invalid percentage", () => {
  assert.throws(() => calculateDiscount(10000, 150), /Invalid discount inputs/);
});
```

```bash
# Terminal တွင် စမ်းသပ် Run ကြည့်ခြင်း
node --test
```

## 3. Graceful Shutdown (`SIGTERM` / `SIGINT`)

VPS သို့မဟုတ် Docker container ကို Restart/Deploy လုပ်တဲ့အခါ Server process ဆီ `SIGTERM` signal ဝင်လာပါတယ်။ လက်ရှိ ဝင်နေဆဲ Requests တွေ ပြီးအောင် စောင့်ပြီးမှ HTTP Server နဲ့ DB Pool ကို သေချာ ပိတ်ပေးရပါတယ်။

```javascript
const server = app.listen(3000, () => {
  console.log("API Server running on port 3000");
});

async function shutdown(signal) {
  console.log(`${signal} received: closing HTTP server...`);
  server.close(async () => {
    await pool.end();
    console.log("Database connections closed safely.");
    process.exit(0);
  });
}

process.on("SIGTERM", () => shutdown("SIGTERM"));
process.on("SIGINT", () => shutdown("SIGINT"));
```
