## 1. Multi-Page Pagination Loop

E-Commerce သို့မဟုတ် Job Listings တွေမှာ Page အများကြီး ရှိနေတဲ့အခါ "Next" link ရှိနေသေးသရွေ့ Loop ပတ်ပြီး `time.sleep()` နဲ့ ယဉ်ကျေးစွာ ဆွဲယူနိုင်ပါတယ်:

```python
import time
from urllib.parse import urljoin
import requests
from bs4 import BeautifulSoup

session = requests.Session()
session.headers.update({"User-Agent": "TakkathoScraperBot/1.0"})

current_url = "https://books.toscrape.com/catalogue/page-1.html"
all_titles = []

for _ in range(5):  # Safety limit: စမ်းသပ်ရန် Page 5 ခုအထိသာ ပတ်မည်
    res = session.get(current_url, timeout=10)
    if res.status_code != 200:
        break

    soup = BeautifulSoup(res.text, "html.parser")
    for h3 in soup.select("article.product_pod h3 a"):
        all_titles.append(h3.get("title", "").strip())

    next_btn = soup.select_one("li.next a")
    if not next_btn or not next_btn.get("href"):
        break

    current_url = urljoin(current_url, next_btn["href"])
    time.sleep(1.0)  # Rate limiting

print(f"Scraped {len(all_titles)} items!")
```

## 2. Pro Trick: Hidden JSON APIs ရှာဖွေခြင်း (DevTools Network Tab)

ခေတ်သစ် Website အများစု (React, Next.js, Vue) ဟာ Page ကို Browser ထဲမှာ JavaScript နဲ့ Render လုပ်တဲ့အတွက် `requests.get(url)` နဲ့ HTML ယူရင် ဗလာ Page ပဲ ရတတ်ပါတယ်။ ဒါပေမဲ့ Backend ကနေ JSON Data ဆွဲယူနေတဲ့ API endpoint ကို Browser DevTools ကနေ အလွယ်တကူ ရှာနိုင်ပါတယ်:

1. Browser မှာ **F12 (Inspect) -> Network Tab -> Fetch/XHR** ကို ရွေးပါ။
2. Webpage ကို Refresh (သို့) Page 2 နှိပ်ကြည့်ပါ။
3. JSON Data တွေ ပြန်ပေးနေတဲ့ Request URL (ဥပမာ `https://api.example.com/v1/products?page=2`) ကို တွေ့ပါက Right-click -> **Copy -> Copy URL** ယူပြီး `res.json()` နဲ့ တိုက်ရိုက် ဖတ်နိုင်ပါတယ်။

```python
# JSON Endpoint မှ Data တိုက်ရိုက် ယူခြင်း (BeautifulSoup မလိုတော့ပါ!)
res = session.get("https://api.example.com/v1/products?page=1", timeout=10)
data = res.json()
for item in data.get("items", []):
    print(item["name"], item["price"])
```

## 3. Retry Strategy (`requests` Session Adapter)

Network ခဏပြတ်သွားတာ သို့မဟုတ် Server ခဏ Overload (`502`, `503`, `429`) ဖြစ်သွားတဲ့အခါ Scraper တစ်ခုလုံး ရပ်မသွားအောင် Auto-retry ထည့်ထားသင့်ပါတယ်:

```python
from requests.adapters import HTTPAdapter
from urllib3.util.retry import Retry

retry_policy = Retry(
    total=3,
    backoff_factor=1.5,              # 1.5s, 3s, 4.5s စောင့်ပြီး ပြန်ကြိုးစားမည်
    status_forcelist=[429, 500, 502, 503, 504],
)
session.mount("https://", HTTPAdapter(max_retries=retry_policy))
```
