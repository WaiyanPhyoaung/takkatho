## 📚 သင်ရိုးတွင် ပါဝင်သည့် Modules ၅ ခု

1. **Module 1: Data Analysis Foundations (`venv`, NumPy & Pandas)** — Vectorized math, DataFrames, GroupBy analytics နှင့် Dirty data cleaning။
2. **Module 2: Data Visualization (Matplotlib & Seaborn)** — Line/Bar/Heatmap charts များ ဆွဲသားပြီး Automated PNG reports ထုတ်ခြင်း။
3. **Module 3: Web Scraping Mastery (`requests` & BeautifulSoup)** — `robots.txt` ethics, CSS selector parsing, Pagination loops နှင့် Hidden JSON APIs ရှာဖွေခြင်း။
4. **Module 4: Headless Browser Automation (Playwright)** — Dynamic JS/SPA sites များ Scrape လုပ်ခြင်း၊ Form filling နှင့် GitHub Actions Cron automation။
5. **Module 5: Capstone Project** — SQLite Price History + Telegram Alert Bot စနစ် အပြည့်အစုံ တည်ဆောက်ခြင်း။
