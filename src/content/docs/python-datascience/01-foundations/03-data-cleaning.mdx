## 1. Missing Values (`NaN`) စစ်ဆေးခြင်းနှင့် ကိုင်တွယ်ခြင်း

```python
import pandas as pd
import numpy as np

df = pd.DataFrame({
    "name": ["Mg Mg", "Su Su", "Kyaw Kyaw", "Su Su", None],
    "city": [" yangon ", "Mandalay", None, "Mandalay", "Yangon"],
    "price_raw": ["25,000 MMK", "18,500 MMK", None, "18,500 MMK", "30,000 MMK"],
})

# Column တစ်ခုချင်းစီမှာ Missing values ဘယ်နှခု ရှိလဲ ကြည့်ခြင်း
print(df.isna().sum())

# 1. နာမည် လုံးဝ မပါသော Row များကို ဖယ်ရှားခြင်း
df = df.dropna(subset=["name"])

# 2. City မပါလျှင် Default တန်ဖိုး "Unknown" ဖြည့်ပေးခြင်း
df["city"] = df["city"].fillna("Unknown")
```

---

## 2. String Cleaning နှင့် Numeric Type Conversion

Web scraping ကနေ ရလာတဲ့ `"25,000 MMK"` လို စာသားတွေကို တွက်ချက်လို့ရအောင် Integer/Float အဖြစ် ပြောင်းလဲပေးရပါမယ်:

```python
# Extra whitespace ဖယ်ရှား၍ Capitalize ညှိခြင်း
df["city"] = df["city"].str.strip().str.title()

# "25,000 MMK" -> 25000.0 သို့ ပြောင်းလဲခြင်း
df["price"] = (
    df["price_raw"]
    .astype(str)
    .str.replace(",", "", regex=False)
    .str.replace("MMK", "", regex=False)
    .str.strip()
)
# Number မဖြစ်နိုင်သော စာသားများ ပါလျှင် Crash မဖြစ်ဘဲ NaN ပြောင်းပေးရန် errors="coerce" သုံးပါ
df["price"] = pd.to_numeric(df["price"], errors="coerce")

# ကျန်ရှိသော NaN price ကို Median (အလယ်တန်ဖိုး) ဖြင့် ဖြည့်ခြင်း
df["price"] = df["price"].fillna(df["price"].median())
```

---

## 3. Duplicate Rows များ ဖယ်ရှားခြင်း

```python
# ထပ်နေသော Rows အရေအတွက် စစ်ဆေးခြင်း
print("Duplicates:", df.duplicated().sum())

# ထပ်နေသော Rows များ ဖယ်ရှား၍ Index ပြန်စီခြင်း
df = df.drop_duplicates(subset=["name", "city"], keep="first").reset_index(drop=True)
print(df)
```
