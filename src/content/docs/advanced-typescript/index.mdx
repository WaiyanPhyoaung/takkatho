## 📚 သင်ရိုးတွင် ပါဝင်သည့် အဓိက Modules များ

1. **Why is Advanced TS Needed?** — TypeScript အခြေခံမှသည် Complex Scenarios များဆီသို့ ကူးပြောင်းရသည့် အကြောင်းရင်း။
2. **Generics** — Reusable functions များ၊ Type inference နှင့် Generic Constraints (`extends`) များ တည်ဆောက်ခြင်း။
3. **Utility Types** — `Partial`, `Required`, `Readonly`, `Pick`, `Omit`, `Record`, `Exclude`, `Extract`, `Parameters`, `ReturnType`, `Awaited` တို့ကို ကျွမ်းကျင်စွာ သုံးစွဲခြင်း။
4. **`satisfies` Keyword** — Type inference ကို မပျက်စီးစေဘဲ Object shape ကို စစ်ဆေးနိုင်သည့် ခေတ်မီ TypeScript feature။
5. **Bringing It All Together** — Mini Project နှင့် Production Tips & Pitfalls များ။
