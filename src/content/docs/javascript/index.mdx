## 📚 သင်ရိုးတွင် ပါဝင်သည့် အဓိက Modules များ

- **Fundamentals & Control Flow** — Variables, Operators, Strings/Numbers, Conditionals (`if/else`, `switch`) နှင့် Loops။
- **Functions, Arrays & Objects** — Arrow functions, Parameters နှင့် Data structures များ။
- **DOM & Events** — DOM Elements ရွေးချယ်ပြုပြင်ခြင်း၊ Styles & Attributes နှင့် Event Bubbling/Listeners။
- **DOM Hands-on Projects** — Counter App, Theme Switcher နှင့် Todo List ကိုယ်တိုင် တည်ဆောက်ခြင်း။
