## 📚 သင်ရိုးတွင် ပါဝင်သည့် Modules ၅ ခု

1. **Module 1: LLM API Foundations** — Stateless Messages API (`system`, `user`, `assistant`), Tokens & Context Window, Temperature, Streaming SSE နှင့် Schema-enforced Structured Outputs (`Pydantic` / JSON Schema)။
2. **Module 2: Function Calling & Tool Use** — LLM မှ External APIs နှင့် SQLite Database များကို လှမ်းခေါ်စေခြင်း၊ Safe ReAct Agent Loop (`max_steps` နှင့် Error Recovery) တည်ဆောက်ခြင်း။
3. **Module 3: Embeddings & Vector Databases** — Semantic Meaning ကို Vectors အဖြစ် ပြောင်းလဲခြင်း၊ Document Chunking strategies၊ `ChromaDB` နှင့် Metadata filtering / Hybrid Search။
4. **Module 4: Retrieval-Augmented Generation (RAG)** — Source Citations ပါဝင်သည့် Document Q&A Pipeline၊ Groundedness prompt design၊ Query Rewriting နှင့် Conversational Memory။
5. **Module 5: Autonomous Multi-Agent Workflows & Production Evals** — Router, Supervisor နှင့် Evaluator-Optimizer Multi-Agent patterns (`LangGraph` / Workflow state)၊ Prompt Injection Guardrails နှင့် Capstone Docs-to-Action Agent။
