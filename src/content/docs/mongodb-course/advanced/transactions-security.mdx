## 1. Offset (`skip`) vs. Cursor Pagination

`skip(50000).limit(20)` သုံးရင် Database က ရှေ့က Records 50,000 ကို အရင်ဖတ်ပြီးမှ ကျော်ရလို့ အရမ်းနှေးသွားပါတယ်။ **Cursor-based pagination** က Index `_id` (သို့မဟုတ် `createdAt`) ကို တိုက်ရိုက် ဖြတ်ရှာတဲ့အတွက် Page 1,000 ရောက်လည်း မြန်နှုန်း မကျသွားပါဘူး။

```javascript
// ❌ Offset pagination (Data များလာလျှင် နှေးကွေးသည်)
await Post.find().sort({ _id: -1 }).skip((page - 1) * 20).limit(20);

// ✅ Cursor-based pagination (Index ကို တိုက်ရိုက်သုံးသည်)
const query = lastSeenId ? { _id: { $lt: lastSeenId } } : {};
const posts = await Post.find(query).sort({ _id: -1 }).limit(20).lean();
```

## 2. Multi-Document ACID Transactions

E-Commerce Order တစ်ခုတင်လိုက်ရင် (1) Order create လုပ်ခြင်း နဲ့ (2) Product stock လျှော့ခြင်း — ၂ ခုလုံး အောင်မြင်မှ အတည်ပြုပြီး တစ်ခုခု မှားယွင်းပါက **Rollback** ပြန်လုပ်ဖို့ MongoDB Replica Set (Atlas တွင် Default ပါဝင်သည်) ပေါ်မှာ Transactions သုံးနိုင်ပါတယ်။

```javascript
const session = await mongoose.startSession();
try {
  await session.withTransaction(async () => {
    await Product.updateOne(
      { _id: productId, stock: { $gte: 1 } },
      { $inc: { stock: -1 } },
      { session },
    );

    await Order.create([{ userId, productId, status: "confirmed" }], { session });
  });
} finally {
  await session.endSession();
}
```

## 3. NoSQL Injection ကာကွယ်နည်း

Login request ထဲမှာ User က String အစား `{ "$ne": null }` ဆိုတဲ့ JSON Object ပို့လိုက်ရင် Query operator အဖြစ် ဝင်ရောက်တိုက်ခိုက်နိုင်ပါတယ်။

- Input validation (`zod`) ဖြင့် `email` နှင့် `password` ကို **String** ဖြစ်ကြောင်း တိကျစွာ စစ်ဆေးပါ။
- Mongoose တွင် `mongoose.set("sanitizeFilter", true)` (သို့မဟုတ် Explicit string casting) ကို အသုံးပြုပါ။
- MongoDB Atlas Network Access တွင် IP Allowlist နှင့် Strong Role-Based Users များသာ ခွင့်ပြုထားပါ။
