## 📚 သင်ရိုးတွင် ပါဝင်သည့် အဓိက Modules များ

1. **မိတ်ဆက်** — SQL ဆိုတာ ဘာလဲနှင့် Relational Database အခြေခံ။
2. **အခြေခံ Queries** — `SELECT ... FROM`, `WHERE` စည်းကမ်းချက်, `ORDER BY` နှင့် `LIMIT`။
3. **ဒေတာပြင်ဆင်ခြင်း (CRUD)** — `INSERT`, `UPDATE`, `DELETE`။
4. **တွက်ချက်ခြင်းများ** — `COUNT`, `SUM`, `AVG`, `GROUP BY` နှင့် `HAVING`။
5. **ဇယားများ ချိတ်ဆက်ခြင်း** — `INNER JOIN`, `LEFT JOIN` နှင့် Multi-table Queries။
6. **ဇယားများ ဖန်တီးခြင်း** — `CREATE`, `ALTER`, `DROP` Table Operations။
