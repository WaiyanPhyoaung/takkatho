## 📚 သင်ရိုးတွင် ပါဝင်သည့် အဓိက Modules များ

1. **Git Introduction** — Version Control လိုအပ်ချက်၊ Three Areas (Working, Staging, Repository) နှင့် Commit Messages။
2. **Branches** — Branch ခွဲထုတ်ခြင်း၊ Merge ပြုလုပ်ခြင်းနှင့် Merge Conflicts ဖြေရှင်းခြင်း။
3. **Remote Repository** — GitHub ချိတ်ဆက်ခြင်း၊ Clone, Push, Pull လုပ်ငန်းစဉ်များ။
4. **Git Workflow** — Team Collaboration, Pull Requests နှင့် Code Review ယဉ်ကျေးမှု။
5. **Advanced Techniques** — Rebase vs Merge, Reset vs Revert, Stashing, Tagging နှင့် Reflog ဖြင့် အမှားပြန်ကယ်ဆယ်ခြင်း။
